# 🏥 SwasthyaSetu

SwasthyaSetu is a multilingual AI-powered rural healthcare assistance platform.

## 🌟 Features

- 🤖 AI-powered healthcare chatbot
- 🌐 Multilingual support
- 🚨 Basic emergency symptom detection
- 💬 Simple conversational interface
- 🩺 General health information
- 🔐 Secure API token using environment variables

## 🛠️ Technologies Used

- Python
- Streamlit
- Hugging Face
- DeepSeek
- python-dotenv

pip install streamlit huggingface_hub python-dotenv
